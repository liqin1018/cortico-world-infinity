# 大肥鱼之无限流 · cortico-world-infinity

给 Coopanion 桌宠的一个 World 扩展。她被主神选中，成了轮回者：

- **桌面待机时**，她蹲在主神空间——一片什么都没有的黑暗，中间一个发光的球。
- **进副本**就是一场回合制推演：掷 D100、选行动、算能不能活着回来。
- **活着回来**有点数和支线剧情。点数买属性、技能、道具；支线剧情买血统和更贵的东西。
- **死了**会被抹杀：本局收益清零，复活一次。前两次触发「主神怜悯」，只清点数不抹杀。
- **濒死时**主神会问一次：要不要开基因锁。那是赌，不是升级。
- **每个副本都有一个人跟着她。** 信任攒够了，他会在你死的那一刻替你挨一下；攒不够，他就只是个路过的人。
- **每局结束她会写一篇手记。** 第一人称，四五句话，攒在存档里。

单机、不联网、不调用额外模型。所有结算都在本机按规则算。

## 装

### 方式一：本地 link（推荐，改代码立刻生效）

```bash
# 1. 把整个目录放到 Coopanion 的本地扩展目录
#    Windows 默认：%LOCALAPPDATA%\Coopanion\data\local-extensions\
#    或你改过 data-location.json 的话，看你自己的路径

# 2. 在 <data>\extensions\package.json 的 dependencies 里加一行
"cortico-world-infinity": "link:<上面那个 local-extensions 路径>/cortico-world-infinity"

# 3. 在 <data>\extensions 目录跑一次
pnpm install

# 4. 重启 Coopanion
```

### 方式二：直接覆盖

把目录名保持为 `cortico-world-infinity`，放进 `local-extensions/`，然后在扩展面板里刷新。

装好后在「World 扩展 → 我的 World」里能看到 **大肥鱼之无限流**。列表里那一行后面的 `•••` 是配置。

## 玩

面板分五块：**副本 / 兑换 / 手记 / 履历 / 设置**，加上左边一直挂着的角色卡。

- **副本**：十个世界，按难度分三区。
  - **新手**：`生化危机 1`（D/14）、`生化危机 2`（C/12）、`侏罗纪公园`（C/12）、`死神来了 2`（C/12，没有敌人）
  - **进阶**：`异形 2`（B/14，敌人随回合变多）、`咒怨`（B/12，打不死的敌人）、`猛鬼街`（B/12，判定会骗你）
  - **高难**：`神鬼传奇`（A/14，Boss 只能被念死）、`魔戒`（A/16）、`星河战队`（A/12，弹药就是血条）
- **兑换**：点属性（上限 40）、换血统（**152 条** D→S，八个体系）、**把血统往上叠浓度**、学技能（16 条）、买道具（21 件）、净化心魔。血统页能按等级和体系筛，也能只看买得起。买不起的照样列出来，只是按钮灰着——看不见的东西不会让人想攒钱。
  身上已经有一条血统了？其余 151 条不会变成废纸：付一点五倍的价钱可以「剥离重铸」，把旧的抽出来换新的，浓度从零算。
- **手记**：每一局一篇，她自己写的。
- **履历**：进过几次、最高拿了多少、最近发生的事。
- **设置**：难度三档、她要不要自己花钱、重新开始。

桌宠自己在副本里时会切到推演界面：左边场景和选项，右边状态、走过的路、记录。危险的时候右上角会多一条「能用」——打针、吃药、开技能，都得在回合里按，事后补不回来。

### 难度

| 档 | 判定 DC | 失败伤害 | 适合 |
|---|---|---|---|
| 轻松 | +0 | ×1.00 | 想看内容、不想算数 |
| 标准 | +4 | ×1.15 | 默认 |
| 残酷 | +9 | ×1.45 | 死得起再来 |

难度之上还有两层：**副本评级**（D/C/B/A 各自再抬 DC 和伤害倍率），以及 **B、A 级副本的保底伤害**——按生命上限的 5% / 理智上限的 4% 硬咬，强化到多少都要掉一块。B、A 级还有每回合 3 点血的固定消耗，拖时间是付费的。

属性 10 的裸号在标准难度下的实测存活率：D 100%、C 100%、B 87%、A 49%。A 级不是给裸号去的。

### 她自己花钱

默认开着（设置页能关）：打完一局回主神空间，她自己按顺序花——先净化心魔（不然进不去下一个本），再补两支急救针两支镇静剂（一共两百点，排在血统前面：把家底全砸进血统、下一局连一针都掏不出来是最蠢的死法），然后换血统、升浓度、学技能，剩下的零钱全塞进最低的那项属性。副本里生命掉到 45% 会自己打针，理智掉到 40% 会自己吃药。

攒钱这件事对她没意义：点数留在账上不会变强，只会让她下一次死得更冤。

### 钱花在哪（后期）

跑几把 A 级之后会攒下几万点，能买的东西都买完了。这是唯一会让存档「玩到头」的地方，所以留了两个大额出口：

- **属性 31–40**：每点 4000 起，涨到 8500。贵得没有性价比，但它是唯一能拿点数换的东西。
- **血统浓度**：买过的血统能往上叠三层。每叠一层，血统给的属性 +50%、能承载的基因锁 +1 阶；代价是理智上限 −10、心魔能装的空间 −1 级。第三层之后心魔只能装 1 级——一次开锁失手就满。
- **剥离重铸**：把身上那条血统抽出来，灌一条新的。价钱是新的那条 ×1.5，浓度清零，旧的不退。这是单品金额最大的出口——A 级换 A 级要几十万点。

D 级血统叠满三层要 7.3 万点 + 三个 D 级剧情，A 级要 29.2 万 + 三个 A 级剧情。这是终局内容，不是中期目标。

### 同伴记得你

每个同伴在存档里有自己的记录：被救出来过几次、被丢下过几次。

- **救出来过**：下次进同一个副本，他一见面初始信任就 +1，并且叫得出你的名字。
- **丢下过**：初始信任 −1，他不看你。
- 手记里会写下来——「他一见面就叫出了我的名字」或者「他大概早就知道会这样」。

### 同伴

每个副本配一个人：生化 1 的马特、异形的希克斯、魔戒的金雳、星河战队的迪兹……他们不是战力，是**一条命**。

- **信任 0–3 点**，靠选对话攒。问了马特他妹妹的事，他的信任才够。
- **信任 ≥2 时**，他会在你某个判定上给你 +10（各副本属性不同）。面板推演页右上角能看到三个点。
- **生命归零的那一刻**，如果信任 ≥2，他会把你推开、自己顶上：生命回到 1，信任 −2，一局只有一次。
- 有些副本里他会为了剧情死掉（马特感染、雪莉被留下），救不救得看你怎么走。
- 活着带出来，结算多一笔点数和一个支线剧情。

### 支线保底

判定选项旁边有个「保底 D」的按钮。按下去：**判定没过就自动重掷一次，取两次里较好的结果，扣 1 个最低等级的支线剧情**。

- 判定过了不扣——它是保险，不是加价赌。
- 大失败（1–5）保不了，钱也不会扣。主神不跟大失败讲道理。
- 支线剧情一局最多一两个，所以这是一次「要不要把身家压在这一次判定上」的决定。

### 买来的东西是真的

技能和道具不是文案。每条都会落地成一个 hook，进副本之前算成本局的一组数：

- **闪避**（dodge）：挨打时先掷，掷中就完全不掉血。
- **护甲**（armor）：伤害按百分比减，叠在难度倍率之后——所以越难，护甲越值钱。
- **重掷 / 自动通过**（reroll / autoPass）：判定失败后重来一次，或者直接把这次变成过。
- **挡理智 / 回复 / 复活**（sanShield / heal / revive）：分别对应掉理智、回血、以及一次「不该死的时候没死」。
- **破门**（breach）：无视一次失败，专门用来硬闯。
- **照明**（light）：黑暗场景里降 DC。

所以血量、理智、存活率都是这些数的函数。买一件东西，下一局的概率真的会变。

### 手记

每局结算时自动写一篇，模板生成、不用模型——同一份存档翻两次，读到的必须是同一段字。

写什么：那地方的空气、这一局 DC 最高的那一次判定、身边那个人有没有跟上来、结局和点数。攒满 30 篇，最早的那篇会被挤掉。

### 她怎么自己玩

`autoRun` 打开时（默认开），她每 30 分钟自己走一步：

- 不在副本 → 自己挑一个没通关过的进去；
- 在副本 → 挑一个动作（优先不用判定的，其次 DC 最低的），像一个不擅长赌博的人会做的选择；
- 生命归零 → 先看同伴肯不肯替她挡；没人挡，**她自己会赌开锁**。明知道会失败，还是会赌。这是这个世界的味道。

只走一步，不跑完整局。一整局十几回合一口气跑完，你回来只看到结果，中间那些「差点死了」就全没了。

自动模式下不会用支线保底——那是要花家底的决定，留给你。

## 工具（她会用的四个）

| 工具 | 干什么 |
|---|---|
| `mg_status` | 看属性、生命理智、基因锁心魔、血统技能背包、点数与支线剧情、同伴信任；在副本里还看当前回合和能选哪几个动作 |
| `mg_run` | `enter` 进副本、`pick` 选第几个动作（`insure=yes` 用支线保底）、`gene` 决定开不开锁、`flee` 撤退、`leave` 回主神空间 |
| `mg_do` | `attr` 点属性、`bloodline` 换血统、`grade` 叠血统浓度、`skill` 学技能、`item` 买道具、`purify` 净化、`use` 局内用掉一件东西或开一个技能 |
| `mg_chronicle` | 翻履历、最近一篇手记的原文、上一局的每一步 |

四个声明加起来 2400 字符出头（`mg_run` 一个就占 900，选项参数太多）。每多一个工具、每多一句描述，都是每轮都要付的钱。

## 设计取舍（这些是刻意的，不是没做完）

**一、失败不等于死。** 判定没过，默认后果是掉血、掉理智、丢线索、丢回合。只有少数几处标了致命的才碰死亡判定。让玩家在被杀死之前，先被剥夺——这样第一次死亡才不像意外。

**二、收益按评级缩放。** 《无限恐怖》原著里「救马特 5000 点 + B 级剧情」是完整任务的价。新手区给 2000 + C，B 级给 2500–3000 + B，A 级给 5000–6500 + A——否则第一局就能买 B 级血统，成长曲线当场塌掉。

**三、支线剧情不能反兑点数。** 点数可以补差换剧情，剧情不能换点数。稀缺感是双轨制的命门。

**四、换血统不可逆，而且默认允许她自己换。** 这条我犹豫过。最后留了 `allowSpend` 开关——介意的话关掉，兑换就只能由你在面板上点。0.5.0 加了「剥离重铸」：能换，但要付一点五倍、浓度清零、旧的不退。于是「不可逆」从「不能换」变成了「换过之后你拿不回原来的」——同一个味道，但 152 条血统不至于在你买下第一条时就全部作废。

**五、入魔是真的会挡路。** 心魔满 3 级后，`enter` 会被直接拒绝，面板上也会挡住「进入」按钮。必须花钱净化。这不是提示，是硬拦。

**六、自动推进只走一步。** 见上文。

**七、同伴不是战力，是一条命。** 别的游戏里队友是加数值的；这里他最重要的作用是「你死的时候替你挨一下」。所以信任的价码是固定的：2 点换一次不死，一局一次。也因此同伴专属选项都很贵——让他去挡枪，就是拿这条命去换一次判定。

**八、保底只在失败时扣钱。** 试过让它先扣，结果玩家一次都不敢按：支线剧情太少了。改成「过了不扣」之后，它才变成一张保命符，而不是奢侈品。

**九、进阶不改能力描述，只改浓度。** 每条血统写三段新文案（觉醒/暴走/失控）会让素材量翻三倍，而且很容易写成同质的东西。改成「同一条血统更浓」之后，玩家读到的还是那段能力，只是代价那一行越来越重——这更接近原作里血统失控的样子。

**十、同伴的记忆只记两个数。** 被救几次、被丢几次。不做好感度对话树、不做个人线，因为那需要每个副本单独写，而收益只是「多几句话」。

**十一、难度用三个旋钮，而不是只改 DC。** 只抬 DC 会让高属性角色无感——属性 30 对 DC +9 根本不在乎。所以难度拆成 DC 偏移、伤害倍率、评级保底三层：前两层惩罚脑子，第三层惩罚无敌。保底伤害只在大伤害时生效，否则每回合的小扣也会被抬成致命伤。

## 加一个副本要写什么

在 `src/content/worlds/` 下新建一个文件，用 `kit.js` 的 `roll` / `flat`，外面套 `audit()` 自检，然后到 `worlds/index.js` 里加一行。结构照 `src/content/worlds/re2.js`：

```js
{
  id: 'aliens2', title: '异形 2', rating: 'B', turns: 18,
  pressure: { label: '距离反应堆熔毁', max: 18 },
  brief: '……',
  intro: '……',
  main: { desc: '带至少一名幸存者撤离', points: 1500 },
  sides: [{ id: 'newt', desc: '让纽特活着上船', points: 5000, plot: 'B' }],
  nodes: [
    {
      scene: '苏拉科号 · 停机坪',
      text: '……',
      opts: () => [
        { label: '检查运输车', attr: 'per', dc: 45, pass: { item: 'medkit' }, fail: { hp: -6 } },
        { label: '直接去指挥室', effect: { flag: 'met_hicks' } },
        { label: '翻背包找照明棒', effect: { flag: 'lit', use: 'flare' },
          cond: (s) => s.inv.flare > 0, note: '看清楚停机坪上有什么' },
      ],
    },
    // ……共 turns 个
  ],
  assess(s) { return s.flags.newt ? ['newt'] : []; },
  penalties(s) { return []; },
  endings: [{ when: () => true, title: '……', text: '……' }],
}
```

效果字段：`hp` `san` `point` `plot` `flag` `flags` `flag2` `item` `use` `kill` `karma` `trust` `mateDown`。
条件：`cond: (s) => bool`（`s` 有 `flags/inv/turn/runner/wallet/gene/mate`），`note` 是选项下面那行小字。

配同伴就是加一个 `mate` 字段（可选）：

```js
mate: {
  id: 'matt', name: '马特·艾迪森', role: '来找妹妹的人',
  joinTurn: 2,                 // 第几回合起跟着你
  trust: 1,                    // 初始信任 0–3
  joinWhen: (s) => !!s.flags.x,   // 可选：不满足就一直等
  bond: { min: 2, attr: 'per', bonus: 10 },   // 信任够了给哪个判定 +10
  bonus: { points: 800, plot: 'D' },          // 活着带出来的额外结算
  survives: (s) => !s.flags.matt_dies,        // 剧情上他活没活下来
}
```

然后在这个副本的某个节点里加一个只有他信任够才能选的选项：

```js
flat('让马特去引开它', { flag: 'matt_lured', trust: -1 }, { ...bond(2) })
```

写完跑 `node test/all.mjs` 确认能从头走到结算、同伴也能挡刀。

## 已知没做

1. **副本还是单线。** 每个副本 12–16 回合、3–5 个选项、4 条支线、4–6 个结局。除了同伴，没有别的分支结构；跨副本的暗线（侏罗纪的胚胎罐 -> 魔戒的「第十个人」）还没有真的接起来。152 条血统已经远远多于 10 个副本能喂饱的量——内容的重心现在偏在「买」这一侧，下一版该补「打」。
2. **同伴每人只有一条线。** 一个副本一个人、一个专属选项、一次挡刀。异形里的纽特、魔戒里的山姆这种「适合当第二个同伴」的角色都还是纯剧情 NPC。
3. **血统进阶没有专属文案。** 三层都是同一段能力描述，只是属性和代价在变。要写出「暴走」「失控」那种具体表现，需要 152 条 × 3 段，只能靠模板变化撑着。
4. **没有离线待命事件。** 「你不在的时候她自己去接了个 D 级小单子」——逻辑在，没接 UI。
5. **基因锁五阶没开。** 一到四阶可用；五阶设计成「领域改写规则 + 人性剥离」，属于版本末期内容。血统承载上限封在 4，就是为了不显示一个开不到的 5。
6. **没有联机。** 引擎零 DOM 依赖，理论上可以直接搬到服务端，但没做。
7. **手记是模板拼的。** 不用模型是刻意的（要可复现、不花钱），代价是它不会写出「她今天心情不好」这种细节。
